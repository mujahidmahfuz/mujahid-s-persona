# demo-lattice-3d — styleguide demo (3D)

Proves the 3D pipeline: poster first, island on visibility, WebGL / reduced-motion fallback,
keyboard controls (arrows, +/−, R), `frameloop="demand"`, render loop paused off-screen and in hidden tabs.

Source anchor: none — toy demo for /styleguide only.
Data provenance: (b) toy geometry from `latticePoints()` in `math.ts`. Labelled "Illustrative example".
