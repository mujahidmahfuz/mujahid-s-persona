## Why it exists

Asking one model gives you one opinion. LLM Council asks several, then lets them judge each other — blind — so that the ranking, not any single model, decides which answer is best. Judging answers blind and aggregating many judges is the approach studied in the paper [_Language Model Council_](https://arxiv.org/abs/2406.08598) (arXiv:2406.08598), which the project builds on.

## How it is built

- **Backend** — a FastAPI app with a three-stage pipeline, an OpenRouter client with retries, and pure functions for prompts, ranking parsing and consensus.
- **API** — `POST /ask-council` returns one JSON result; `POST /ask-council/stream` streams stage-by-stage events.
- **Frontend** — a React + Vite round-table interface. Peer review can be switched off to use fewer model calls.
