## Features

- **Session timer** — a state machine that tracks a scrolling session.
- **Lock overlay** — a full-screen overlay when a session runs too long.
- **Escalating reminders** before the lock.
- **Mission Mode** and a **“Save Me”** action.
- **AI coaching** — the app calls a FastAPI service, which uses Groq to run Llama 3.3 70B.
- **Native usage tracking** (Kotlin), a **Net Momentum** score, **streaks** and **CSV export**.

The app is in closed testing on Google Play.
