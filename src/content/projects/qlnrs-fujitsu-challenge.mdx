## Why it exists

QLNRS was built for the Fujitsu Quantum Simulator Challenge 2025–26. The task was vehicle routing: planning routes for a fleet of vehicles. The project tests whether a quantum subroutine can help inside a classical search method.

## How it works

Large neighbourhood search (LNS) improves a solution by repeatedly destroying part of it and repairing it:

<Flow
  title="One turn of the search"
  source="QLNRS final report (CONTENT-INVENTORY §4)"
  steps={[
    { label: 'Current routes', detail: 'A full solution to the vehicle-routing instance.' },
    { label: 'Destroy', detail: 'Remove part of the routes, chosen by a risk-weighted rule.' },
    { label: 'Repair with CP-QAOA', detail: 'Rebuild the removed part on a feasibility-preserving subspace simulator.' },
    { label: 'Accept or reject', detail: 'Keep the new routes or the old ones, then repeat.' },
  ]}
/>

1. **Destroy** — remove part of the current routes, chosen by a risk-weighted rule.
2. **Repair** — rebuild the removed part with CP-QAOA run on a subspace simulator.
3. **Accept or reject** the new solution, then repeat.

The quantum part uses a transposition mixer and a k²-dimensional encoding. CP-QAOA ran on a local subspace simulator; a single penalty-QUBO circuit was run on Fujitsu's mpiQulacs (job 7911328) to confirm the hardware path and the infeasibility baseline.
